# Tip Jar

A tip jar on Base. Connect a wallet, leave a message, it posts to the wall. No account, no fees, no middleman.

- Contract: `0x6D886Ccb59074b0F6bCD9A7e1b9f3c842Ce50E91`
- Explorer: https://basescan.org/address/0x6D886Ccb59074b0F6bCD9A7e1b9f3c842Ce50E91
- Network: Base (8453)

Tips go straight to the contract. The owner withdraws to the owner address. Messages are stored in the `Donation` event and rendered on the page.

## Files

`index.html` — the entire frontend. One file, no build step.
